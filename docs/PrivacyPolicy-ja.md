# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者の提供するサービス「Quick Buy」（以下「本サービス」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報および収集方法
本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき提供者が収集するものを意味するものとします。

### ユーザーが登録する情報（端末内にのみ保存されます）
本サービスでユーザーが登録するお気に入りの商品（店のドメイン、商品の識別子、商品名、個数等）は、**ユーザーの端末内にのみ保存され、提供者のサーバーに送信されません**。提供者はこれらの情報を収集・閲覧できません。

- 保存期間: ユーザーが本サービス内の操作で削除するまで、または本アプリを削除するまで、端末内に保存されます
- 削除方法: 本サービス内でお気に入りを削除するか、本アプリを端末から削除することで消去できます
- 端末の変更・初期化・本アプリの削除により登録した情報が失われた場合、提供者は復旧できません

### 購入画面を開く時に外部ストアへ送られる情報
本サービスは、ユーザーの操作に応じて、第三者が運営するオンラインストアおよび EC サイト（以下「外部ストア」といいます。）の購入画面を開きます。この時に開く URL には、店のドメイン、商品の識別子、個数のほか、本サービスを経由したことを示す値（流入元を示す値、アフィリエイトプログラムの識別子）が含まれる場合があります。氏名・メールアドレス等のユーザー個人を特定する情報は URL に含めません。

また、本サービスは、ユーザーがお気に入りに入れる商品ページの URL を入力または共有した時に、その商品の名前、画像および商品の識別子を表示するため、その URL の外部ストアから商品の情報を取得します。この時に外部ストアへ送るのは、ユーザーが入力または共有した URL に含まれる店のドメインと商品の識別子です。商品の画像は、お気に入りを表示する時に、その外部ストアまたは外部ストアが利用する画像の配信サービス（Shopify の cdn.shopify.com）から読み込みます。これらの通信では、通信に伴う情報（IP アドレス等）が通信先に送られます。

外部ストアの画面でユーザーが入力する情報（ログイン情報、配送先、決済情報等）および外部ストアが取得する情報は、外部ストアの運営者が、その運営者のプライバシーポリシーに基づき取り扱います。提供者は、外部ストアのログイン情報、配送先、決済情報および購入履歴を取得しません。

### 提供者が収集する情報
本サービスはアカウント登録を必要とせず、提供者がユーザーの個人情報をサーバーで収集・保管することはありません。ユーザーがメール等で問い合わせを行った場合に限り、その連絡先と問い合わせ内容を対応のために利用し、対応の完了後、対応の記録として必要な期間が過ぎたものを削除します。

## 利用目的
利用者情報の具体的な利用目的は以下のとおりです。

- 本サービスの提供、維持、保護および改善のため
- 本サービスに関するご案内、お問い合わせ等への対応のため
- 本サービスに関する提供者の規約、ポリシー等に違反する行為に対する対応のため
- 本サービスに関する規約等の変更などを通知するため

## 広告および紹介料
本サービスには、アフィリエイトプログラムによるリンクが含まれる場合があります。ユーザーが本サービスを経由して外部ストアで商品を購入した場合に、提供者が紹介料を受け取ることがあります。紹介料の算定のために外部ストアまたはアフィリエイトプログラムの運営者が取得する情報は、その運営者のプライバシーポリシーに基づき取り扱われます。

## 第三者提供
提供者は、利用者情報のうち、個人情報については、あらかじめユーザーの同意を得ないで、第三者（日本国外にある者を含みます。）に提供しません。ただし、次に掲げる必要があり第三者（日本国外にある者を含みます。）に提供する場合はこの限りではありません。

- 提供者が利用目的の達成に必要な範囲内において個人情報の取扱いの全部または一部を委託する場合
- 合併その他の事由による事業の承継に伴って個人情報が提供される場合
- 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、ユーザーの同意を得ることによって当該事務の遂行に支障を及ぼすおそれがある場合
- その他、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令で認められる場合

本ポリシーの制定時点で、提供者が個人情報の取扱いを委託している事業者はなく、外国にある第三者への個人情報の提供も行っていません。

## 解析・広告・外部 AI サービス
本ポリシーの制定時点で、本サービスは、利用状況を解析するための SDK、広告を配信するための SDK および広告識別子を使用していません。また、ユーザーの情報を外部の AI サービスへ送信しません。これらを導入する場合は、導入する事業者の名称、送信する情報および利用目的を本ポリシーに記載します。

## 個人情報の開示・訂正・利用停止・消去
提供者は、ユーザーから、個人情報保護法の定めに基づき個人情報の開示・訂正・利用停止・消去を求められたときは、ユーザーご本人からのご請求であることを確認の上で、遅滞なく対応します（当該個人情報が存在しないときにはその旨を通知いたします。）。ただし、個人情報保護法その他の法令により提供者が義務を負わない場合は、この限りではありません。

なお、端末内にのみ保存されているお気に入りの商品等は提供者が保有していないため、ユーザー自身が本サービス内の操作または本アプリの削除により消去できます。

## プライバシーポリシーの変更手続
提供者は、必要に応じて、本ポリシーを変更します。ただし、法令上ユーザーの同意が必要となるような本ポリシーの変更を行う場合、変更後の本ポリシーは、提供者所定の方法で変更に同意したユーザーに対してのみ適用されるものとします。なお、提供者は、本ポリシーを変更する場合には、変更後の本ポリシーの施行時期および内容をアプリ上での表示その他の適切な方法により周知し、またはユーザーに通知します。
